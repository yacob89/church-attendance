# Church Attendance App

A minimalist Flutter application for managing church attendance, members (saints), and meetings.

## Features

- **Authentication**: Secure login using Supabase Auth.
- **Saints Management**: Add, edit, and delete member profiles.
- **Tags Management**: Categorize saints with custom tags (e.g., status, service groups).
- **Meetings**: Schedule and manage church meetings.
- **Attendance Tracking**: Record and view attendance for each meeting.
- **Minimalist Design**: Clean, distraction-free UI following Material Design 3 guidelines.

## Tech Stack

- **Frontend**: Flutter (Android, iOS)
- **Backend**: Supabase (PostgreSQL, Auth)
- **Navigation**: GoRouter
- **State Management**: Standard Flutter state management (StatefulWidget) with Repositories.

## Getting Started

### Prerequisites

1.  **Flutter SDK**: Ensure you have the latest Flutter SDK installed.
2.  **Supabase Project**: You need a Supabase project with the following schema.

### Database Schema (SQL)

Run the following SQL in your Supabase SQL Editor to set up the tables:

```sql
-- Tags
create table tags (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  type text not null,
  name text not null
);

-- Saints
create table saints (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  city text,
  address text,
  phone text,
  school text,
  meeting_hall text,
  birthdate timestamp,
  note text
);

-- Meetings
create table meetings (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  meeting_date timestamp,
  note text
);

-- Saints Tags (Join Table)
create table saints_tags (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  saints_id bigint references saints(id) on delete cascade,
  tags_id bigint references tags(id) on delete cascade
);

-- Meetings Attendance (Join Table)
create table meetings_attendance (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  meetings_id bigint references meetings(id) on delete cascade,
  saints_id bigint references saints(id) on delete cascade
);
```

### Installation

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd church_attendance
    ```

2.  **Install dependencies**:
    ```bash
    flutter pub get
    ```

3.  **Configure Supabase**:
    Open `lib/core/constants/supabase_constants.dart` and add your credentials:
    ```dart
    class SupabaseConstants {
      static const String supabaseUrl = 'YOUR_SUPABASE_URL';
      static const String supabaseAnonKey = 'YOUR_SUPABASE_ANON_KEY';
    }
    ```

4.  **Run the app**:
    ```bash
    flutter run
    ```
